# 个人记账模块 — 需求文档

## 1. 业务背景

用户日常使用手机记账软件记录收支，希望将手机导出的 CSV 数据导入桌面端进行统一管理和分析。桌面端提供更便捷的筛选、编辑和可视化统计能力，弥补手机端在批量操作和数据分析方面的不足。

## 2. 功能列表

### 2.1 交易记录管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 记账列表 | 分页展示所有收支记录，含金额、分类、日期、备注、支付方式 | P0 |
| 新增记录 | 手动录入一笔收入或支出 | P0 |
| 编辑记录 | 修改已有记录的任意字段 | P0 |
| 删除记录 | 删除单条记录（二次确认） | P0 |
| 多维度筛选 | 按类型（收入/支出）、分类、日期范围、备注关键字筛选 | P0 |

### 2.2 CSV 批量导入

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 文件选择 | 通过文件对话框选择本地 CSV 文件 | P0 |
| 格式兼容 | 自动识别列头，兼容"日期,类型,分类,金额,备注"格式 | P0 |
| 数据预览 | 导入前展示前 5 条数据供用户确认 | P1 |
| 智能分类 | CSV 中的分类名称自动匹配已有分类，不存在的自动创建 | P0 |
| 错误报告 | 导入完成后展示成功/失败数量及具体错误原因 | P1 |
| 事务原子性 | 导入失败时全部回滚，不产生脏数据 | P0 |

### 2.3 分类管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 预置分类 | 启动时自动插入 16 个常用分类（10 支出 + 6 收入） | P0 |
| 分类列表 | 支出/收入分 Tab 展示 | P0 |
| 新增分类 | 自定义添加分类名称 | P1 |
| 编辑分类 | 修改分类名称 | P2 |
| 删除分类 | 删除自定义分类 | P2 |

### 2.4 数据统计

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 月度收支汇总 | 页面顶部展示本月收入、支出、结余 | P0 |
| 日期范围选择 | 日期范围选择器 + 快捷选项（近一周/一月/三月/一年） | P0 |
| 每日收支折线图 | ECharts 折线图，展示选定时间段内每天的收入和支出趋势 | P0 |
| 支出分类饼图 | 饼图展示支出分类占比 | P1 |
| 收入分类饼图 | 饼图展示收入分类占比 | P1 |

## 3. 数据模型

### 3.1 分类表 (category)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| name | TEXT | NOT NULL | 分类名称 |
| type | TEXT | NOT NULL, CHECK('income','expense') | 收入/支出 |
| icon | TEXT | DEFAULT '' | 图标标识（预留） |
| sort_order | INTEGER | DEFAULT 0 | 排序权重 |

### 3.2 交易记录表 (transactions)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 主键 |
| type | TEXT | NOT NULL, CHECK('income','expense') | 收入/支出 |
| amount | REAL | NOT NULL | 金额（正数） |
| category_id | INTEGER | NOT NULL, FK→category.id | 所属分类 |
| trans_date | TEXT | NOT NULL | 交易日期 (YYYY-MM-DD) |
| description | TEXT | DEFAULT '' | 备注 |
| payment_method | TEXT | DEFAULT '' | 支付方式 |
| create_time | TEXT | NOT NULL | 创建时间 |
| update_time | TEXT | NOT NULL | 更新时间 |

## 5. CSV 导入规范

### 支持的格式

```csv
日期,类型,分类,金额,备注
2025-01-15,支出,餐饮,35.00,午餐
2025-01-15,收入,工资,15000.00,1月工资
2025-03-20,支出,交通,8.5,地铁通勤
```

### 格式说明

| 列 | 是否必填 | 允许值 |
|----|---------|--------|
| 日期 | ✅ | YYYY-MM-DD 或 YYYY/MM/DD |
| 类型 | ✅ | "支出"/"expense" 或 "收入"/"income" |
| 分类 | ✅ | 任意文本（自动匹配或新建） |
| 金额 | ✅ | 正数，支持小数 |
| 备注 | ❌ | 任意文本 |

### 导入行为

- 自动跳过空行
- 金额自动忽略千分位逗号
- 不存在的分类自动创建
- 导入失败的记录不影响成功记录
- 全部导入在一个事务内完成（失败全部回滚）

## 6. 页面导航结构

```
┌─ 记账管理 — TransactionList.vue （默认打开）
│   ├─ 统计卡片（本月收入/支出/结余）
│   ├─ 筛选栏（类型/分类/日期/关键字）
│   ├─ 交易列表（分页表格）
│   ├─ TransactionDialog.vue（新增/编辑弹窗）
│   └─ CsvImportDialog.vue（CSV 导入弹窗）
│
├─ 数据统计 — StatisticsView.vue
│   ├─ 日期范围选择器
│   ├─ 每日收支折线图（ECharts）
│   └─ 分类占比饼图（支出 + 收入）
│
└─ 人员管理 — UserList.vue （原项目保留）
```
